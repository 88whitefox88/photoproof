# ФотоДоказ — камера для фотофиксации доказательств (iPhone)

Приложение фотографирует, ставит на снимок штамп с датой, временем и местом и сразу заверяет снимок так, чтобы потом можно было доказать: фото сделано в указанное время и в указанном месте, после съемки не изменялось и снято именно этим телефоном.

> **Важно.** Ни одно приложение не может гарантировать, что суд примет доказательство: суд оценивает доказательства сам (ст. 67 ГПК РФ, ст. 71 АПК РФ). Фотографии допустимы как доказательства и без этого приложения. Приложение закрывает главное уязвимое место: заявление другой стороны, что фото подделано или сделано в другое время. Подробнее: [docs/court-guide.md](docs/court-guide.md).

## Как защищен снимок

| Возражение другой стороны | Чем приложение его опровергает |
|---|---|
| «Дата подкручена, часы телефона переставили» | Хеш снимка сразу подписывают **независимые службы штампов времени** (RFC 3161: FreeTSA, DigiCert, Sectigo). Часы телефона сверяются с эталоном; если они расходятся, на штамп идет эталонное время. |
| «Фото отредактировано» | SHA-256 оригинала записан в подписанный паспорт снимка. Подпись делается ключом, созданным в чипе **Secure Enclave**; извлечь его из телефона нельзя. Изменение хотя бы одного байта обнаруживается. |
| «Фото взято из интернета или снято раньше» | Загрузить готовую картинку в приложение нельзя, только снять камерой. **Apple App Attest** подтверждает, что подписывало оригинальное приложение на настоящем iPhone. |
| «Место не то» | Координаты GPS с точностью в метрах. iOS сообщает о программной подмене координат, и приложение отмечает это на штампе. |
| «Часть снимков удалили или подменили» | **Журнал с цепочкой хешей**: каждая съемка и каждое удаление фиксируются, разрыв цепочки виден при осмотре телефона. |
| «Штамп закрывает часть кадра» | Штамп печатается **под** кадром, изображение не перекрывается. Оригинал без штампа тоже хранится в пакете. |

## Что получает пользователь

Каждый снимок сохраняется как пакет (экспортируется в ZIP):

```
1_original.jpg                     оригинал с камеры, не изменялся
2_stamped.jpg                      копия со штампом (дата, время, координаты, №, QR-код)
manifest.json                      паспорт снимка: время, место, устройство, SHA-256 всех файлов
manifest.sig                       подпись паспорта ключом Secure Enclave
device_public_key.pem              открытый ключ для проверки
tsa/*.tsr                          метки доверенного времени на снимок и на паспорт
appattest_*.cbor/.txt              аттестация Apple App Attest
manifest.appattest-assertion.cbor  подпись паспорта аттестованным ключом
report.pdf                         акт фотофиксации для печати (с местом для подписи)
README.txt                         пошаговая инструкция по проверке для эксперта
```

Номер снимка (например `3F9A-12C4-88B0`) — это начало SHA-256 оригинала, поэтому штамп однозначно связан с файлом.

## Установка на iPhone

Собрать приложение для iPhone можно только на macOS. Если Mac нет, его заменяет бесплатная облачная сборка GitHub. Есть три пути.

### Путь А. Без Mac, бесплатно: GitHub + Sideloadly (с Windows)

1. Зарегистрируйтесь на [github.com](https://github.com), создайте **приватный** репозиторий и загрузите в него эту папку. Проще всего через [GitHub Desktop](https://desktop.github.com): *File → Add local repository → d:\photo_date → Publish*.
2. Откройте вкладку **Actions** репозитория. Сборка запускается сама и идет 10–15 минут. Когда появится зеленая галочка, откройте сборку и скачайте артефакт **PhotoProof-unsigned-ipa**. Внутри ZIP лежит `PhotoProof-unsigned.ipa`.
3. Установите на компьютер **iTunes** и **iCloud** в версиях с сайта Apple (не из Microsoft Store), затем [Sideloadly](https://sideloadly.io).
4. Подключите iPhone кабелем и нажмите на телефоне «Доверять этому компьютеру». В Sideloadly выберите `.ipa`, введите Apple ID и нажмите **Start**.
   *Совет: заведите для этого отдельный Apple ID, а не основной.*
5. На iPhone включите **Настройки → Конфиденциальность и безопасность → Режим разработчика** (телефон перезагрузится). Затем откройте **Настройки → Основные → VPN и управление устройством** и нажмите «Доверять» напротив своего Apple ID.

Ограничения бесплатного пути:
- Apple разрешает такой установке работать **7 дней**. Потом приложение нужно переустановить через Sideloadly тем же Apple ID. Снимки и ключ при переустановке сохраняются; **не удаляйте приложение перед переустановкой и не меняйте Bundle ID**.
- **App Attest**, скорее всего, будет недоступен. Остальная защита (Secure Enclave, метки времени, журнал) работает полностью.

### Путь Б. Без Mac, платно: TestFlight

Нужен аккаунт [Apple Developer Program](https://developer.apple.com/programs/) ($99 в год). Тогда облачный сервис (Codemagic, GitHub Actions с ключом App Store Connect или Xcode Cloud) подписывает сборку и отправляет ее в TestFlight. Приложение ставится на iPhone через приложение TestFlight как обычное, работает 90 дней между обновлениями, App Attest доступен. Если выберете этот путь, автоматическую подпись в облачной сборке нужно будет настроить отдельно.

> Оплата Apple Developer Program картами российских банков сейчас может быть недоступна.

### Путь В. Есть Mac (свой, знакомых или арендованный в облаке, например MacinCloud)

```bash
brew install xcodegen
cd photo_date
xcodegen generate
open PhotoProof.xcodeproj
```

В Xcode откройте *PhotoProof → Signing & Capabilities*, выберите свою команду (Team), подключите iPhone и нажмите **Run**.

### Перед первой сборкой

Идентификатор приложения задан в [project.yml](project.yml) (`ru.fotodokaz.k7m2q9`). Не меняйте его после первой установки: иначе iPhone посчитает приложение новым, и снимки останутся в старом. Для путей Б и В впишите Team ID в `DEVELOPMENT_TEAM`.

Бесплатные минуты GitHub Actions: в приватном репозитории сборка на macOS расходует лимит примерно в 200 минут в месяц (одна сборка — около 5–10 минут); в публичном репозитории ограничений нет.

## Проверка пакета (для юриста или эксперта)

Без программирования, стандартными средствами Windows и OpenSSL: инструкция лежит в `README.txt` внутри каждого пакета.

Автоматически, одной командой:

```bash
pip install -r verify/requirements.txt
python verify/verify.py PhotoProof_2026-11-17_14-32-05_3F9A-12C4-88B0.zip ^
    --tsa-ca cacert.pem ^
    --apple-root Apple_App_Attestation_Root_CA.pem
```

- `cacert.pem` — корневой сертификат FreeTSA: https://freetsa.org/files/cacert.pem
- `Apple_App_Attestation_Root_CA.pem` — https://www.apple.com/certificateauthority/Apple_App_Attestation_Root_CA.pem
- Корни DigiCert и Sectigo скрипт находит в системе сам.

Скрипт проверяет контрольные суммы, подпись паспорта, подписи и цепочки сертификатов служб времени, а также цепочку App Attest до корня Apple. Код возврата `0` означает, что нарушений нет, `1` — что найдено изменение.

## Ограничения (честно)

- Метка времени доказывает, что файл существовал **не позднее** указанного момента. То, что снимок сделан **не раньше**, подтверждается косвенно: приложение снимает только живой камерой, а интервал от съемки до метки записан по монотонным часам.
- Приложение не защищает от **инсценировки**: от съемки экрана с чужой фотографией или постановочной сцены. Делайте общий план, крупные планы и, по возможности, видео или съемку при свидетелях.
- На взломанном (jailbreak) телефоне можно подменить GPS. App Attest затрудняет, но полностью не исключает такие сценарии.
- Службы FreeTSA, DigiCert и Sectigo — иностранные, они не аккредитованы по 63-ФЗ. Их метки — проверяемое криптографическое доказательство, но не «квалифицированная электронная подпись». Для максимальной силы используйте нотариальное обеспечение доказательств (см. [docs/court-guide.md](docs/court-guide.md)).
- Адрес по координатам определяется сервисом Apple и указан справочно. Доказательственное значение имеют координаты.

## Структура проекта

```
project.yml                 описание Xcode-проекта (XcodeGen)
Support/Info.plist          разрешения (камера, геопозиция) и настройки
PhotoProof/
  App/                      точка входа, навигация
  Camera/                   AVFoundation: съемка только живой камерой
  Location/                 GPS, признак подмены координат, адрес
  Security/                 RFC 3161 (свой ASN.1 DER), Secure Enclave, App Attest
  Evidence/                 конвейер фотофиксации, паспорт, журнал, ZIP, README пакета, проверка
  Rendering/                штамп с QR-кодом, акт PDF
  UI/                       экраны SwiftUI
verify/verify.py            независимая проверка пакета (Python)
docs/court-guide.md         как использовать снимки в суде
.github/workflows/ios.yml   облачная сборка на macOS + .ipa для Sideloadly
```

Требования: iOS 16+, iPhone. Сторонних библиотек нет.
